# FindSnap - 智能视觉寻物助手

**团队编号**：第18组  
**团队成员**：[@chliyieng](https://github.com/chliyieng)

## 项目简介
FindSnap 是一款基于 AI 图像识别的寻物辅助 App。拍照即可记录物品与场景，通过关键词搜索快速找回物品位置。

## 核心功能
- 📸 **Snap & Tag**：拍照自动识别物品并打标签
- 🔍 **Smart Search**：关键词检索历史照片
- 🗂️ **场景记录**：保存拍摄时的位置上下文

## 技术栈
- Android (Kotlin / Java)
- AI 图像识别 API
